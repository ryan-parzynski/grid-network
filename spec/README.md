# Specification

Normative protocol specifications for Grid Network.

## Files

- `PROTOCOL.md` — The protocol specification (v0.6.2, design-review). Normative requirements for identity, relationships, authorization, revocation, reachability, transport integration, deployment model, failure semantics, and reconciliation.
- `OBJECTS.md` — Byte-level encoding and cryptographic constructions for all signed objects. Canonical CBOR profile, object serialization, signature semantics, common stream envelope, registered domain separators.
- `TEST-VECTORS/` — Byte-exact test vectors (to be created).

## Reading Order

1. `PROTOCOL.md` — Start here for the protocol specification.
2. `OBJECTS.md` — Reference for implementers needing encoding details.
3. `TEST-VECTORS/README.md` — When test vectors exist, for conformance testing.
