## Planned Examples

- **Pairing:** Two devices establishing a relationship via QR code.
- **Service grant:** Granting access to a specific capability (e.g., Jellyfin.stream).
- **Reachability:** Publishing and resolving current network endpoints.
- **Direct connection:** Establishing a direct WireGuard tunnel.
- **Relay fallback:** Using a relay when direct connectivity fails.
- **Revocation:** Removing a lost device's access.
- **Identity rotation:** Rotating an Identity Root key.
- **App integration:** Immich/Jellyfin/Nextcloud connecting via local agent.
